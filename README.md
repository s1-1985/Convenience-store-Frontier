# Convenience-store Frontier

1970年代後半から始まり、日本のコンビニ業態と地域の生活習慣が相互に変化していく経営シミュレーションゲームです。

## コンセプト

プレイヤーは一店舗から事業を始め、営業時間、品ぞろえ、発注、納品、人員配置を改善します。目的は単に売上を増やすことではありません。

必要な時間に、必要な商品を、安定して買える店を作ることで、住民の朝食、昼食、夜間購買などの行動が変化します。その市場成長を競合も学習し、同じ街の業態そのものが発展していきます。

## 現在の開発段階

最初に制作するのは、ゲーム内30日・実プレイ45〜70分の垂直スライスです。

検証する主要判断は次の6つです。

- 営業時間
- カテゴリ別売場面積
- カテゴリ別発注方針
- 納品回数
- 時間帯別人員
- 店内作業の優先順位

## 垂直スライスの核

1. 朝の需要を逃している店を見る
2. 早く開店すると客が増える
3. レジ混雑と補充遅延が起きる
4. 弁当を増やすと廃棄が増える
5. 二回納品で改善すると物流費と作業負担が増える
6. 安定運営により住民の購買習慣が変わる
7. 競合が成功した業態要素を模倣する

## 開発原則

- 特定の商品トレンドでゲーム全体を代表させない
- 生活文化はプロジェクト報酬ではなく、顧客行動の結果として生まれる
- 一つの改善が次の経営問題を生む
- 通常業務は自動化し、重要な例外だけをプレイヤーへ示す
- 店内表示と内部シミュレーションを一致させる
- 一つの設定がすべての局面で最適にならないようにする
