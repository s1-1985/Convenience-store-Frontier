# Convenience Store Frontier — Adopted Asset Package v1

## 採用ライン

このパッケージは、`コンビニ店員8種のドット絵スプライトシート.png` を採用版の起点とし、
それ以降に作成した現行アセットを整理したもの。

途中で「什器に左右方向の角度が付いている」として却下された旧什器案は除外し、
後から作り直した正面系の一般什器を優先して収録する。

## 共通ビジュアル仕様

- 2Dドット／HDピクセルアート寄り
- 店内モックの雰囲気を基準
- 什器は原則として真正面＋わずかな上方見下ろし
- 左右への3/4角度は付けない
- キャラクターは正面・背面・左右＋必要に応じて斜め4方向
- 歩行差分を持たせる
- 店員は作業状態ごとの差分も将来的に拡張する
- 文字は基本的にゲーム側で描画し、画像へ焼き込まない

## 什器と商品の分離

商品棚の「器」と中身は別レイヤーで扱う。

例：

- 常温棚 + お菓子
- 常温棚 + 日用品
- 常温棚 + カップ麺
- 冷蔵棚 + 飲料
- 冷蔵棚 + デザート
- HOT什器 + ホットスナック

同じ什器を使いながら中身の商品カテゴリを差し替えられる設計とする。

## 一般什器カテゴリ

現行ベースでは以下を扱う。

- 常温
- 冷蔵
- 冷凍
- HOT
- レジ／サービスカウンター
- バックヤード／設備
- 建具／店内構造物
- 商品中身モジュール

## 年代仕様（今後）

このゲームは1970年代から現在までの日本のコンビニ発展を描く。
一般什器が一通り揃った後、同じ機能の什器について年代別外観を制作する。

予定：

- 1970年代
- 1980年代
- 1990年代
- 2000年代
- 2010年代
- 2020年代〜現在

年代によって筐体デザイン、材質感、照明、色、什器サイズ、電子化の程度などを変える。
