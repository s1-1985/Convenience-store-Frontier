Convenience Store Frontier - Fixture Asset Package

Contents:
- 01_general: generic fixture sheets
- 02_store_equipment: register, equipment, floor/store structure sheets
- 03_era_variants: era-based fixture sheets (retro, 80s, 90s, modern-Japan, modern, near-future)
- 04_product_modules: separate merchandise/content modules for fixture fill variants

Note:
- Fixtures and product contents are separated so one fixture can be reused with different content sets.
- All files are the adopted/latest PNG sheets currently available in this workspace.
