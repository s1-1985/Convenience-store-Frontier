# ADR-0012: 元ファイルの再調査で実データテーブルを発見、カテゴリ定義を修正

Status: Accepted
Date: 2026-10-09

## Context

ユーザーから3度目の「MDで解析されてないものは取り掛からなくていい」との確認を
受け、残っている移植候補(§2/§3客需要・購買行動、§8.2出店判断)が本当に
「解析データが無い」のか、元ファイル(`Conveni-PS1-Claude-Handoff.md`、
128,871行)を再調査した。

結果、以前「断片のみ」「未解読」と判断していた箇所の一部に、**実際には実データが
埋め込まれていた**ことが判明した。128,871行という分量のため、最初の抽出時には
読み切れていなかった。

### 見つかった実データ

- `demand-tables.json`: 月別天候抽選の12ヶ月分の閾値表、PS1原作の商品0〜26番の
  季節区分配列、客グループ(街タイル→客プロファイル割当)、週間カレンダー、
  営業時間スケジュール3種
- `town-building-tables.json`: 街の建物カテゴリ表。72種類の建物について、id・
  レベル範囲・category(0〜10)・日本語名称が実データとして収録されている。
  これにより、`src/simulation/townGrowth.ts`の`TownTileCategory`の対応が
  **誤っていたことが判明した**: category==3は「空き地等」ではなく「住宅」
  (id43〜49の7種)、空き地はcategory==0(id9〜13)だった
- `layout-tables.json`: ライバル出店時のレイアウト表。30種類、3段階のサイズ
  (20×20/24×24/28×26)。什器配置自体(raw_hex)は今回未解読

### それでも見つからなかったもの

- 144客プロファイルそれぞれの実データ(重み・出現率・しきい値)。該当する
  Pythonコードは実機バイナリ(ゲームの実行ファイル本体)から直接読み出す形式で、
  値そのものは元ファイルに収録されていない。実行ファイル自体は本セッションには
  アップロードされていない
- 建物種別→人口加算値の対応表(`0x8009FF1C`)の実際の値。読み取りアルゴリズムの
  記述はあるが、同様に実機バイナリからの抽出コードのみ
- 新築時の建物種別選択アルゴリズム(「6種/7種」の具体的な候補リスト)

## Decision

1. `src/simulation/townGrowth.ts`の`TownTileCategory`型とコメントを、
   `town-building-tables.json`の実データに基づいて修正する(0=空き地、
   1=道路/線路、2=コンビニ、3=住宅、4=会社、5=娯楽・飲食店、6=公園、7=学校、
   8=公共施設、9=役所、10=誘致用地)。これはコード動作を変更しない
   (`category===3`を実際に使っている箇所は無いため)、ドキュメント・型定義の
   正確性のみの修正である。
2. `design/ps1-reference/algorithms.md`・`README.md`へ、新たに見つかった実データ
   (月別天候閾値の全12ヶ月分、商品季節区分配列、建物カテゴリ表、レイアウト表)を
   反映する。
3. それでも§2/§3(客需要・購買行動の本体)・§8.2(出店の什器配置・土地費用)・
   §4(町人口集計の実際の人口加算値)は、**144プロファイルの実データ・人口対応
   表の実際の値・什器配置の生データ形式**が元ファイルに収録されていないため、
   引き続き移植を見送る。これは「エンジニアリング規模が大きいから」ではなく、
   ユーザー自身の基準(「MDで解析されてないものは取り掛からなくていい」)に
   従った判断である。

## Consequences

- 今後、元ファイルを再アップロードする際は、128,871行という分量を踏まえ、
  `## <ファイル名>.json`という見出し形式で埋め込まれた実データブロックを
  `grep`等で網羅的に探索することを標準の手順とする(今回のように、本文の
  説明文だけを読んで「未解読」と判断するのは早計な場合がある)。
- 144プロファイルの実データ・建物種別→人口対応表の実際の値は、ゲームの実行
  ファイル本体(`SLPS_007.82`)からの抽出が必要であり、引継ぎファイルの
  テキストだけでは得られない。これらが必要になった場合は、ユーザーに実行
  ファイル自体(またはその抽出結果)の提供を依頼する必要がある。
