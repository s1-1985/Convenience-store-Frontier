# ローカル・プレイテスト計測

垂直スライスの試作合格条件を、実際のプレイ操作から確認するための計測機能です。

## 基本方針

- 計測データはブラウザ内の `localStorage` にだけ保存する
- 外部サーバーへの送信は行わない
- 直近20セッションを保存する
- JSON出力後、必要なファイルだけを開発担当へ渡す
- ゲームのシミュレーション結果や方針へ影響を与えない

## 記録する内容

### セッション

- シード
- シナリオ名
- 開始・終了日時
- 実プレイ時間
- 完了日
- 完走・リセット・再読み込みなどの終了理由
- 最終評価のランク、名称、点数

### 操作

- 再生・停止
- 15分進行
- 1日進行
- 7日進行
- 30日目まで進行
- リセット
- レポート操作

### 重要判断

「方針を反映」を押した回数ではなく、前回から実際に設定が変わった場合だけ一回の重要判断として数えます。

- 営業時間
- 発注方針
- 納品方式
- 時間帯別人員
- 作業優先順位
- 売場面積

複数項目を同時に変更した場合は、一回の経営判断として記録し、変更した項目を内訳として保存します。

### 店内表示からの気づき

店内表示を見て次の問題に気づいた時点で、試作計測パネルのボタンを押します。

- 行列
- 空棚
- 閉店後客
- 作業滞留
- 廃棄

同じ問題は一セッションにつき一回だけ記録されます。その日の経営レポートを操作する前に押した場合は、「数値を見る前に気づいた」として集計されます。

## 一セッションの判定

次の条件を表示します。

1. 30日を完走した
2. 実プレイ時間が45〜70分
3. 実際の方針変更を6回以上行った
4. 3種類以上の問題に気づき、その60％以上がレポート操作前だった

これは一人分の参考判定です。最終的な「テスター60％以上」の判定には複数セッションが必要です。

## 複数セッション集計

保存済みセッションから次を集計します。

- セッション数
- 完走率
- 完走者の中央値プレイ時間
- 45〜70分達成率
- 重要判断6回達成率
- 数値前の視覚発見率
- 一セッション判定を満たしたテスター割合

5セッション以上を標本到達の目安とし、視覚発見条件を満たしたテスターが60％以上の場合に、店内可視化の受入判断に必要な基礎データが揃ったと表示します。

## JSON出力

試作計測パネルの「JSON出力」を押すと、現在のセッション、保存履歴、集計結果を一つのファイルに出力します。

出力例：

```text
convenience-store-frontier-playtest-1977-1785570000000.json
```

## 再読み込みとリセット

ゲーム自体は再読み込みで最初から始まるため、途中の計測だけを継続すると不整合になります。そのため、再読み込み前のセッションは `reloaded` として履歴へ保存し、新しいセッションを開始します。

「最初から」を押した場合も、それまでの計測を `reset` として保存してから新しいセッションを始めます。
