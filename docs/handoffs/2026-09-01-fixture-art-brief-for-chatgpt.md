# 什器アート作成ブリーフ(ChatGPT向け)

作成日: 2026-09-01
対象: `data/assets/store/fixture-bases.png` の拡張(常温・冷蔵・冷凍・HOTの一般什器アセット)

このドキュメントは、什器アセットの画像生成をChatGPT側で行う方針が決まったことを受けて、
そのまま作業に着手できるようまとめたブリーフである。背景・調査の詳細は
`docs/store-fixture-zones.md`を参照。

## 1. 今回作るもの

「年代を特定しない、一般的な」什器アセットを温度帯ごとに揃える。**年代別(70年代・80年代…)の
見た目バリエーションは今回のスコープ外。** まず一般版を揃えてから、後日別作業として年代版を作る。

具体的には、`fixture-bases.png`に空の什器(商品が乗っていない状態)を2種類追加する。

| 什器名 | 温度帯 | 現状 |
|---|---|---|
| `ambient_gondola`(常温ゴンドラ) | 常温 | 既存(変更不要) |
| `refrigerated_case`(冷蔵ケース) | 冷蔵 | 既存(変更不要) |
| `frozen_case`(冷凍ケース) | 冷凍 | **新規作成対象** |
| `hot_case`(ホットケース) | HOT(温) | **新規作成対象** |

※ 弁当(`ready_meal`)は今回は`refrigerated_case`のまま据え置くことが決まっている。つまり
`frozen_case`/`hot_case`は今回はまだどのカテゴリの商品も乗せる予定がない「空の什器の見た目」
だけを先に用意する。新しい商品カテゴリ(冷凍食品・おでん・中華まん等)を実際にゲームへ追加する
かどうかは別途ゲームデザイン側の判断待ち。

## 2. 技術仕様(必ず守ること)

- **スタイル**: 2Dドット絵(ハードエッジ・ピクセルアート)。既存の`ambient_gondola`/
  `refrigerated_case`と統一感のあるタッチ・線の太さ・配色トーンにすること。
- **視点**: 正面から「わずかに見下ろし」の角度で統一。側面パネルが見えるような斜め視点にしない。
- **画像サイズ**: 1セル384×256px。既存の`fixture-bases.png`は2列×1行(768×256px)の
  アトラス画像なので、`frozen_case`と`hot_case`を追加すると4列×1行(1536×256px)になる。
  既存2セルの内容(座標・見た目)は変更しないこと。
- **背景**: 透過PNG。背景を透過にできない生成方法を使う場合は、マゼンタ(#FF00FF)などの
  はっきりしたキーカラーでベタ塗りし、後処理でクロマキー抜きすることを前提に、什器本体の
  意匠にマゼンタ・紫・ピンク系の色を一切使わないこと(過去に什器の陰影色がマゼンタに近く、
  クロマキー抜きの際に紫の縁が残る不具合が発生したため)。
- **什器は空の状態**: 商品は載せない(商品オーバーレイは別レイヤーの`merchandise.png`で
  後から重ねる方式のため)。

## 3. 温度帯ごとの参考イメージ

初代『ザ・コンビニ』シリーズ(1996年『ザ・コンビニ ～あの町を独占せよ～』および
1997年『ザ・コンビニ2』)の什器構成を参考にする。実店舗のコンビニ什器としても一般的な形状で
問題ない。

- **冷凍ケース(`frozen_case`)**: 上開き・スライド式ガラス扉のアイランド型冷凍ショーケース、
  または縦型リーチインの冷凍庫。庫内に薄い霜・冷気の演出があってもよい。
- **ホットケース(`hot_case`)**: 保温灯付きの温蔵ショーケース、または鍋型のおでん什器。
  暖色系のランプ・湯気の演出があってもよい。

## 4. 完成後の受け渡し・組み込み手順

1. 生成した画像を`frozen_case`・`hot_case`として384×256pxの2セルにまとめ、既存の
   `fixture-bases.png`(768×256px、2セル)と同じセル順・形式で1536×256px(4セル)の
   PNGに合成する。
2. `data/assets/store/fixtures-manifest.json`の`fixtureBases`に以下のようなエントリを
   追加する(`index`は3列目=2、4列目=3):
   ```json
   "frozen_case": { "atlas": "fixture-bases.png", "index": 2, "accepts": [] },
   "hot_case": { "atlas": "fixture-bases.png", "index": 3, "accepts": [] }
   ```
   `accepts`(乗せられる商品カテゴリ)は現時点で空配列でよい(まだ対応カテゴリが無いため)。
3. コード側(`src/game/storeOperationsEngine.ts`の`FixtureKind`への`frozen_case`/`hot_case`
   追加、`src/ui/storeArtAssets.ts`のアトラス定義更新)はClaude Code側で対応する。
