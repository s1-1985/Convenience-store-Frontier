# 什器アート作り直し依頼(ChatGPT向け)

作成日: 2026-09-03
背景: `convenience_store_frontier_session_assets_2026-09-03.zip`(9枚)で受領した
什器アセットが、今回のゲームの描画方式と合わない形で生成されていたための
作り直し依頼。

## 1. 何が問題だったか

2026-09-03に受け取った9枚の画像は、**すべて什器本体と商品中身が1枚の絵に
合成された状態**で生成されていた。中には`06_fixture_catalog_infographic.png`の
「什器本体と商品中身は完全分離」、`07_era_fixture_grid_catalog.png`の「商品中身は
含まれません(什器のみ)」のように、**画像自身に「分離済み」と注記されているのに
実際の絵には商品が描き込まれている**ものもあった。

このゲームの什器描画は、空の什器画像(`fixture-bases.png`)と商品オーバーレイ画像
(`merchandise.png`)を実行時に重ねて描画し、商品オーバーレイ側を在庫率に応じて
横方向にクロップ表示することで「棚の商品が売れて減っていく/空になる」という
見た目のフィードバックを実現している(`docs/store-art-assets.md`「什器と商品の
組み替え」参照)。什器と商品が1枚に焼き込まれた画像では、この在庫連動表示が
実現できない。

## 2. 今回依頼したいこと

**什器本体(空の状態)と、商品オーバーレイ(什器の中身だけ)を、別々の画像ファイル
として生成してほしい。** 「1枚の絵の中でレイヤー分けされている」ではなく、
**ファイルそのものを分ける**こと。

- `fixture_<name>_empty.png` — 什器本体のみ。棚板・扉・筐体・照明等は描くが、
  商品(ドリンク・スナック・弁当・雑誌等)は一切描かない
- `merchandise_<category>.png` — 商品陳列だけを、什器の枠に対応する透明背景の
  上に描く(什器の外枠・筐体は一切描かない)

生成後に自己確認してほしい点: **`fixture_*_empty.png`を単独で見たとき、棚や
ケースの中に何も商品が無い状態に見えるか?** を実際に目で見て確認してから
納品すること(前回、キャプションと実際の絵が食い違っていたため)。

### 対象什器(優先度順)

1. **最優先: 冷凍(`frozen_case`)・HOT(`hot_case`)の商品オーバーレイ**
   `data/assets/store/fixture-bases.png`には冷凍・HOTの空の什器本体は既に
   本物のアートがあるが、`merchandise.png`側に冷凍食品(冷凍餃子・冷凍うどん)・
   ホットスナック(おでん・中華まん)の商品オーバーレイがまだ無い。この2つが
   埋まれば、既存の4温度帯すべてで商品陳列が実際に表示されるようになる
2. 常温棚(`shelf`)・冷蔵ケース(`cold_case`)の空什器バリエーション追加
   (幅違い・形状違い等)。既存の`ambient_gondola`/`refrigerated_case`と統一感の
   あるタッチ・線の太さ・配色トーンにすること
3. レジ・サービス什器(セルフレジ、ATM、コーヒーステーション等)は現状の
   `FixtureKind`(shelf/cold_case/frozen_case/hot_case/register/backroom/
   entrance/waste)に対応する種類が無いため、**今回は見送り**。新しい什器の
   「種類」自体を追加するかどうかはコード側の設計判断を要するため、まずは
   既存4種類(常温・冷蔵・冷凍・HOT)の充実を優先する

### スコープ外(今回は依頼しない)

- 年代別(1970年代〜2020年代)の見た目バリエーション。前回の9枚には
  1970s/1980s/2020s等のスタイル差分が含まれていたが、**年代に応じて什器を
  切り替えるゲーティングの仕組み自体がまだゲームに実装されていない**
  (`docs/store-fixture-zones.md`5節参照)。実装が追いつくまでは年代を
  特定しない「一般的な」見た目のみでよい
- レジ・サービス什器等、現行`FixtureKind`に無い新しい什器の種類

## 3. 技術仕様(必ず守ること)

`docs/handoffs/2026-09-01-fixture-art-brief-for-chatgpt.md`と同じ仕様を踏襲する。

- **スタイル**: 2Dドット絵(ハードエッジ・ピクセルアート)。既存アセットと統一感の
  あるタッチ・線の太さ・配色トーンにすること
- **視点**: 正面から「わずかに見下ろし」。左右3/4角度や側面パネルが見える斜め
  視点にしない
- **背景**: 透過PNG。透過にできない場合はマゼンタ(#FF00FF)等のクロマキー
  キーカラーでベタ塗りし、什器本体の意匠にマゼンタ・紫・ピンク系の色を使わない
- **什器本体(`fixture_*_empty.png`)**: 商品を一切描かない、空の状態
- **商品オーバーレイ(`merchandise_*.png`)**: 什器の外枠を描かず、商品陳列のみ。
  在庫が減った際の横方向クロップ表示に使うため、陳列を横一列に並べ、左右
  どちらから切り取っても不自然にならない構図にすること(既存の
  `merchandise.png`の陳列構図を参考にすること)

## 4. 完成後の受け渡し

セル数・アトラス構成はこちらで既存の`fixture-bases.png`/`merchandise.png`へ
合成するので、納品時は個々の什器・カテゴリごとに分けたファイル単位でよい
(無理に1枚のアトラスへまとめる必要はない)。ファイル名は上記の命名例を参考に、
何の什器/カテゴリかが分かる名前にすること。
