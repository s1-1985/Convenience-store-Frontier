# 店内営業画面のゲーム素材

Milestone 15では、承認済みの画面モックと生成素材の方向性を、ゲームで安定して使えるSVGアトラスへ整理して取り込む。

## アトラス

| ファイル | 内容 | セル構成 |
|---|---|---|
| `fixtures.svg` | 店内什器12種 | 4列×3行、384×256px/セル |
| `staff.svg` | レジ・補充・清掃の店員、前後左右 | 4列×3行、192×256px/セル |
| `customers.svg` | 客8種、前後左右 | 4列×8行、160×220px/セル |
| `icons.svg` | 時間・店舗・商品・発注・人員・情報・設定・天気 | 8列×1行、128×128px/セル |

## 文字の扱い

画像内の文字はゲーム表示に使用しない。商品カテゴリ名、日付、時刻、売上、警告、ボタン名はゲーム側で日本語フォントとして描画する。これにより端末解像度や表示倍率が変わっても文字を読める状態に保つ。

## 描画解像度

ゲーム座標は従来どおり1080×500を維持する。Canvasの内部バッファだけを端末の`devicePixelRatio`に合わせ、最大3倍まで高解像度化する。画面比率を維持して中央へ配置し、営業画面と売場編集オーバーレイを同じ解像度へそろえる。

## フォールバック

素材の読み込みに失敗した場合は、既存の矩形による仮描画へ戻す。素材障害によって営業シミュレーション自体が停止しない構成とする。

## 実機確認

Android横画面で、上部の時刻・所持金、棚の商品名、在庫警告、右側の営業数値、下部メニューが拡大表示でも判読できることを確認する。売場編集時は営業Canvasと編集Canvasの位置およびタップ座標が一致していることも確認対象とする。
