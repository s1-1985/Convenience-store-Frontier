# ゲームデザイン正本

## 1. ゲームの核

『Convenience-store Frontier』は、コンビニ企業の成長と、日本の地域生活の変化を相互にシミュレートする経営ゲームである。

基本ループは次の通り。

```text
街と住民の生活
↓
時間帯・客層別の需要
↓
店舗運営と品ぞろえ
↓
顧客体験と購買履歴
↓
生活習慣・競争環境の変化
↓
新たな経営問題
```

プレイヤーは市長ではない。店舗と企業を経営し、その結果として街へ影響を与える。

## 2. 歴史進行

ゲームは1970年代相当から始まり、日本のコンビニ史を参考に年代が進行する。

- 1970年代：長時間営業、即食食品、少量即時購入
- 1980年代：弁当・おにぎりの日常化、宅配受付、公共料金収納
- 1990年代：高度物流、ATM、チケット、デザート、高品質弁当
- 2000年代：金融、EC受取、多機能端末、高級PB
- 2010年代：店内コーヒー、冷凍食品、スマートフォン、キャッシュレス
- 2020年代以降：省人化、即時配送、AI発注、災害・高齢地域インフラ

インフラは架空の研究ツリーではなく、時代と社会条件により解禁される。

## 3. 会社の成長

```text
一店舗
→ 地域チェーン
→ 全国チェーン
→ 小売複合企業
```

会社が成長するほど、操作量を増やすのではなく、意思決定の単位を変える。

- 店舗段階：営業時間、売場、発注、人員
- 地域段階：店舗テンプレート、出店、物流、地域戦略
- 本部段階：商品開発、PB、情報能力、人材、ブランド
- 複合企業段階：提携、買収、再開発、事業再編

## 4. 生活文化

生活文化は研究完了報酬ではない。顧客の反復行動から形成される。

例：

- 通勤途中の朝食購入
- 店舗での昼食調達
- 夜間の不足品購入
- 少量を必要時に買う習慣
- 宅配や収納サービスを生活インフラとして使う習慣

各文化は二つの尺度を持つ。

- 地域定着度：地域全体へどれだけ普及したか
- 自社寄与度：普及に自社がどれだけ貢献したか

市場を作った企業が、必ずしも市場を独占し続けるとは限らない。

## 5. 商品とサービス

通常管理はカテゴリ単位とし、個別管理は次へ限定する。

- 新商品
- PB
- 季節商品
- 看板商品
- 生活文化を動かす重点商品

商品評価は売上だけでなく、次を含む。

- 利益
- 欠品
- 廃棄
- 売場効率
- 集客
- 併売
- リピート
- ブランド・文化への寄与

## 6. 中心的な葛藤

- 欠品と廃棄
- 品ぞろえと効率
- 営業時間と人件費
- 鮮度と物流費
- 速度と接客
- 標準化と地域適応
- メーカー商品とPB
- 先行投資と後発効率
- 市場育成と競合参入

改善は問題を消すだけでなく、次の問題を生む。

## 7. 顧客シミュレーション

顧客は三層で扱う。

1. 地域統計
2. 顧客コホート
3. 画面上の代表顧客

内部数値と画面上の行動は一致させる。

画面に長い列があるなら、内部でも待ち時間が発生している。棚が空なら、内部でも棚欠品が発生している。

## 8. 競合

競合は以下の方針を持つ。

- 先駆者
- 高速追随
- 低価格
- 高品質
- 地域特化
- サービス統合

競合はプレイヤーの内部情報を見ない。営業時間、行列、店頭変更、地域需要など観察可能な情報から判断する。

競合参入によって地域市場が成長し、自社シェアだけが低下する場合もある。

## 9. 情報能力

プレイヤーは生の内部数値を直接見ない。

- 帳簿
- 簡易集計レジ
- POS
- 分析本部
- 高度予測

という発展により、見える情報と原因説明が改善する。

情報そのものを会社能力として扱う。

## 10. UI原則

主要画面は次の四層。

- 街
- 店舗
- 本部
- 企業史

通知は問題を示すだけでなく、原因階層を持つ。

```text
売上低下
→ 昼の来店減少
→ 弁当欠品増加
→ 午後便遅延と補充不足
```

## 11. 勝利と失敗

単一の最終勝利ではなく、企業史として評価する。

例：

- 生活文化の先駆者
- 地域の灯
- PB革新者
- 高速回転の達人
- 物流帝国
- 地域密着企業

失敗も経験・企業史として残す。資金危機、早すぎる拡大、品質事故、物流崩壊などは、即座にプレイを終わらせるより再建判断へつなげる。

## 12. 現在の制作範囲

現在は一店舗・30日間の垂直スライスを制作する。

この段階で証明するのは、全国展開ではなく次の体験である。

> 必要な時間に必要な商品を安定して買える店を作ることで、地域住民の生活行動が変わる。
