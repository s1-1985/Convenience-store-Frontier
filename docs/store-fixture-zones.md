# 店舗什器の温度帯区分と年代別ビジュアル方針

## 1. 背景

`docs/game-design.md`の「2. 歴史進行」で、コンビニは1970年代相当から現在まで年代を追って発展する
ことになっている。什器の見た目もこの発展に合わせて年代ごとに更新したい、という方針が決まった。

このドキュメントは次の2段階で進める作業のうち、第1段階(仕様策定)の記録である。

1. **仕様策定(このドキュメント)**: 温度帯(常温・冷蔵・冷凍・HOT)ごとの什器分類を決め、
   年代別ビジュアル差分は仕様として記録するだけに留める。
2. **一般アセット作成(未着手)**: まず年代を特定しない「一般的な」什器アセットを一通り揃える。
3. **年代版アセット作成(未着手)**: 一般アセットが出揃ってから、70年代・80年代・90年代…と
   10年区切りで見た目のバリエーションを作る。

## 2. 現状の実装とのギャップ

`src/game/storeOperationsEngine.ts`の`FixtureKind`は現在

```
"shelf" | "cold_case" | "register" | "backroom" | "entrance" | "waste"
```

の6種類のみで、温度帯は`cold_case`(冷蔵・実質1種類)と`shelf`(常温・実質1種類)の2値しか
表現できていない。冷凍・HOT(温)の概念は無く、`StoreCategoryId`(drinks/dessert/ready_meal/
snacks/instant/daily_goods/magazines)もすべてこの2種類のどちらかに割り当てられているだけである
(`ready_meal`=弁当ですら`cold_case`扱いで、実店舗にあるようなホットケースの弁当・中華まん・
おでんという区別が無い)。

## 3. 参考: ザ・コンビニ / ザ・コンビニ2 の什器体系

ユーザー指示により、初代『ザ・コンビニ ～あの町を独占せよ～』(1996年, マスターピース)の什器構成を
踏襲する。初代単体の詳細な什器一覧はWeb上に十分な資料がなかったため、同一シリーズで資料が豊富な
『ザ・コンビニ2 ～全国チェーン展開だ！～』(1997年)の攻略Wikiも合わせて参照した(初代の拡張版で
あり、基本の温度帯区分は共通と判断)。

初代で確認できた要素(攻略FAQ等より):
- 常温棚: 食品、日用品、傘、御守り等の雑貨
- 冷蔵棚
- 冷凍ケース
- 雑誌・書籍什器
- レジ
- 装飾什器: 観葉植物、ベンチ、噴水

ザ・コンビニ2の設備一覧(攻略Wikiより、12カテゴリ):

| カテゴリ | 内容 |
|---|---|
| 常温棚(小/中/大)+ワゴン | 弁当、パン、インスタント食品、お菓子、本・雑誌、文房具、電気製品、レトルト、調味料、日用品、薬品、下着、お酒、野菜、魚介類、肉 |
| 冷蔵棚(小/中/大)+ワゴン | 冷たい飲料 |
| 冷凍棚(小/中)+ワゴン | 冷凍食品、冷凍菓子 |
| ショーケース(ホット) | 保温飲料ケース、おでんケース、中華まんケース |
| 自販機 | たばこ、冷飲料、中型温冷飲料自販機 |
| レジ・宅配便申込書 | レジ |
| コピー機 | コピー機 |
| イベント什器 | 季節商材等 |
| ディスプレイ | 観葉植物、ベンチ、噴水、ゲームソフト什器 |
| 駐車場 | 駐車場 |
| 休憩室 | 従業員休憩室 |
| その他 | 上記に含まれない什器 |

このゲームの本質は「弁当が常温棚ではなく実は複数の温度帯什器(常温パン/冷蔵飲料/冷凍食品/
ホットケースのおでん・中華まん)にまたがって置かれる」という点にあり、これは実店舗の温度帯構成
(常温・冷蔵・冷凍・HOT)とも一致する。

## 4. 温度帯区分(このゲームでの提案)

`FixtureKind`に温度帯を明示的に持たせる方向で、次の4区分を基本とする。

| 温度帯 | FixtureKind案 | 該当する既存/新規StoreCategoryId |
|---|---|---|
| 常温 | `shelf`(既存) | `snacks`, `instant`, `daily_goods`, `magazines` (既存のまま) |
| 冷蔵 | `cold_case`(既存名を温度帯限定の意味に変更) | `drinks` (既存)、将来的に乳製品等を分離する余地あり |
| 冷凍 | `frozen_case`(新規) | 新規`StoreCategoryId`として`frozen_food`を追加する必要がある(冷凍食品・アイス) |
| HOT | `hot_case`(新規) | `ready_meal`は現在`cold_case`扱いだが、実態としてはホット(弁当・中華まん・おでん)に
  近いカテゴリを含む。`ready_meal`を`hot_case`へ付け替えるか、`ready_meal`を「常温/ホットの
  混在カテゴリ」として据え置き、新規に`hot_snack`(おでん・中華まん)を切り出すかは要検討 |

`dessert`(デザート)は温度帯として冷蔵が妥当なため`cold_case`のまま維持する想定。

## 5. 年代別ビジュアル差分の方針(仕様のみ、未実装)

`docs/game-design.md`の年代区分に合わせ、什器の見た目を10年区切りで変える。

- 1970年代: 簡素な木製什器、開放型の常温棚中心、冷蔵・冷凍什器は小型で数が少ない
- 1980年代: 弁当・おにぎり常態化に伴いホットケース登場、什器がやや明るい配色に
- 1990年代: 什器のデザインが均質化・大型化(ゴンドラ什器の一般化)
- 2000年代: 什器がより洗練され、ブランドカラーが強く出る
- 2010年代: 店内コーヒーマシン、冷凍食品什器の拡充、什器が最新のコンビニに近づく
- 2020年代以降: 省人化機器(セルフレジ等)の導入

この年代差分は**今回は仕様として記録するのみで、アセットは作らない**。まず年代を問わない
「一般的な」什器アセットを温度帯ごとに一通り揃えてから着手する。

## 6. 決定事項(2026-09-01)

1. **`ready_meal`(弁当)は現状の`cold_case`扱いのまま据え置く。** 新設する`frozen_case`・
   `hot_case`は今回、既存カテゴリの再分類を伴わない。まずは対応カテゴリの無い「空の什器」の
   見た目だけを揃える。冷凍食品・おでん・中華まん等の新カテゴリを実際にゲームへ追加するか
   どうかは、別途ゲームデザイン側の判断待ち。
2. **什器アセットの生成はChatGPT側が担当する。** キャラクター素材と同じ方針。作業ブリーフを
   `docs/handoffs/2026-09-01-fixture-art-brief-for-chatgpt.md`にまとめた。Claude Code側は、
   アセットが揃った後の`FixtureKind`拡張・アトラス定義・マニフェスト更新などコード側の
   組み込みを担当する。

## 7. コード側の準備状況(2026-09-01時点)

画像の取り込みを待たずに進められる範囲として、`FixtureKind`型と描画パイプラインの型レベルの
準備を先行して行った。実際に絵や商品が乗る状態ではないため、プレイ上の見た目は変わっていない。

- `src/game/storeOperationsEngine.ts`: `FixtureKind`に`"frozen_case"`・`"hot_case"`を追加。
  ただしどの`StoreCategoryId`もこれらを対象にしておらず、`createDefaultStoreLayout`や
  売場編集UIもこれらの種類の什器を一切生成しないため、**現状これらの値を持つ什器はゲーム内に
  1つも存在しない**(型としてのみ準備済み)。
- `src/ui/storeArtAssets.ts`: `resolveFixtureArtIndex`/`isMerchandiseFixture`/`rotatable`が
  この2種類も温度帯什器として認識するよう更新。ただし`frozen_case`/`hot_case`用の
  `fixture-bases.png`セルはまだ存在しないため、`FIXTURE_BASE_INDEX`にはこの2種類を意図的に
  含めていない(存在しないセル座標を読みに行くのを防ぐため)。該当する`StoreCategoryId`が
  今後追加されるまでは、この描画パス自体に到達しない。
- `src/ui/storeGameRuntime.ts`: `drawFallbackFixture`(アセット未読み込み時に使われる矩形描画)
  に、この2種類の温度帯を示す色(冷凍=氷色`#bfe3f2`、HOT=温色`#e8a24a`)を追加。実際に
  什器が置かれるようになった際、絵が無くても最低限の見た目で描画できる。
