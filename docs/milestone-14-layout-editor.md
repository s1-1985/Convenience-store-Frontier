# Milestone 14：制約付き売場レイアウト編集

## 位置づけ

本Milestoneは、試作中の禁止事項である「自由建築」を解禁するものではない。

建物外形、壁、入口、バックヤード、店舗面積は固定したまま、既に存在する商品棚・冷蔵ケースを店内グリッド上で移動・回転する。目的は、什器配置と以下の営業結果を直接つなぐことである。

- 客の入店から商品棚までの歩行距離
- 商品棚からレジ列までの歩行距離
- バックヤードから棚までの補充距離
- 複数経路が集中する通路
- 品切れや行列へ至る店員作業の遅れ

## 操作原則

スマートフォン横画面での利用を前提に、ドラッグ操作だけへ依存しない。

1. 「店舗」を押して売場編集へ入る
2. 移動する棚をタップする
3. 移動先の床タイルをタップする
4. 必要に応じて90度回転する
5. 動線評価と無効理由を確認する
6. 配置を確定して営業画面へ戻る

一手戻す、初期配置、取消を常に利用できる。

## 配置制約

次のいずれかを満たさない配置は確定できない。

- 設備が店舗内へ収まる
- 設備同士が重ならない
- 客が各商品棚の正面へ立てる
- 補充員が各商品棚の補充位置へ立てる
- 入口から各商品棚へ到達できる
- 各商品棚からレジ列へ到達できる
- レジ列から出口へ到達できる
- バックヤードから各商品棚へ到達できる
- バックヤードからレジへ到達できる

## 可視化

編集画面では次を表示する。

- 平均客動線
- 最大客動線
- 平均補充動線
- 最大補充動線
- 経路集中度
- 総合配置スコア
- 客動線と補充動線が集中するタイルのヒートマップ

これらは正解配置を一つに固定するためではなく、入口寄り、レジ寄り、バックヤード寄りのどこへ棚を置くかというトレードオフを読めるようにするための情報である。

## 営業状態の引継ぎ

配置変更時には、棚在庫、バックヤード在庫、店員配置、当日KPIを維持する。

一方、旧レイアウト上の座標を持つ客、行列、床のゴミ、店員の移動経路、一時作業進捗は安全のため整理し、店員をバックヤードへ戻した状態で新レイアウトを開始する。

配置は端末へ保存し、次回起動時にも復元する。ゲーム全体のリセット時には初期配置へ戻す。

## 対象外

- 建物外形・壁・敷地の編集
- 入口、出口、バックヤードの移動
- レジの増設・撤去・移動
- 什器購入費、工事費、工期
- 店舗面積の拡張
- 複数店舗
