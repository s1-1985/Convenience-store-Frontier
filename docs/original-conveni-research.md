更新: 2026-09-05

対象: PS1 / SS 初代『ザ・コンビニ ～あの町を独占せよ～』

## 0. 目的と調査ルール

本プロジェクトのPhase 1では、現代化やFrontier独自要素を先に足さず、まず初代家庭用版のゲームシステム・UI・経済・AI・時間進行・街発展を可能な限り忠実に再現する。

証拠優先順位:

1. 初代PS1説明書
2. PS5 Console Archives版 / 初代PS ROMの実画面・実挙動
3. 初代PS1/SS実プレイ動画・スクリーンショット
4. 初代PS/SS版専用攻略資料・当時の長期プレイ記録
5. 『ザ・コンビニ2』『III』等は候補・比較用のみ。初代で独立確認できない値はPhase 1へ直接輸入しない

証拠ランク:

- A: 説明書または初代PS/PS5実画面・直接観測
- B+: 初代PS/SS専用資料が複数一致、または強い実プレイ証拠
- B: 初代対象の単一または比較的強い記録
- C: 単一の弱い記録・攻略投稿
- D: 実挙動からの推論
- E: 仮説

原作の不自然なAI・仕様上の癖もPhase 1では勝手に改善しない。純粋な入力/UIバグとゲームシステム上の癖は区別して記録する。

### 素質/上限の対応

- 学歴 → 教育 / レジ / 警備側と関係 [B+]
- 敏捷性 → 補充上限と関係 [B+]
- 社交性 → 清掃 / 接客上限と関係 [B+]
- 個人差/例外があるため単純式ではなくキャラクターごとのgrowth capを持つ方が安全

### 成長

- レジ作業でレジ能力上昇 [B+]
- 補充1回で補充+1という記録 [B+]
- 清掃1回で清掃+1という記録 [B+]
- 警備の成長条件: UNKNOWN
- 接客の成長条件: UNKNOWN
- 店長の教育が部下の成長速度に影響 [B+]
- 教育は通常作業では成長しない [B+]

### 体力・休憩

- max staminaとcurrent staminaを分けるべき
- レジ/補充/清掃で体力消費 [B+]
- 体力0で休憩室へ戻り、回復後に復帰 [B+]
- 敏捷性が休憩回復効率へ影響する記録 [B]
- 敏捷性=歩行速度とは断定しない

### 客に怒られたペナルティ

教育・体力を除く実務5能力が-2という記録 [B+]。


- 通常growth capを超えて上昇可能 [B+]

## 15. Staff AI / タスク選択

- プレイヤーは「レジ担当」等を直接指示できない [B+]
- 店員が自律的に仕事を選ぶ [B+]
- レジ客がいても補充等の現在作業をすぐ中断しない [B+]
- レジは常時絶対最優先ではない [B+]
- 2人が同時にレジへ向かう場合がある [B+]
- 競合した片方が休憩室へ戻り、しばらく出てこない挙動 [B+]
- レジ担当自身も体力切れで離脱し、客がいるのに無人レジが発生し得る [B+]
- 後から来た客が先に会計されることがある [B+]
- 厳密FIFOではない [B+]

有力仮説 [D]:

- レジ列は明示的FIFOキューではなく、各客がアクセスセルを目指しNPC衝突で自然形成している
- レジ/タスクの事前予約が弱い、または無い
- タスク競合時に休憩室へフォールバックする

未確定:

- 補充 vs 清掃の正式な優先順位
- レジ要求の閾値が待ち時間か人数か
- 休憩復帰後の選択式

## 17. 顧客ストレス / 怒り

怒りの原因はレジ待ちだけではない。

初代攻略記録から少なくとも:

- レジ混雑 [B+]
- 店内の詰まり/経路阻害 [B+]
- 品切れ [B]

客タイプごとに怒りやすさが違う可能性が強い [B-/C+]。おじさん/おばさん、老人系は特に短気という複数のプレイ記録があるが、正確な秒数は未確定。

有力実装モデル [D]:

```
CustomerInstance
  patienceThreshold
  frustration

queue wait      -> frustration+
path blocked    -> frustration+
out of stock    -> frustration+

frustration >= patienceThreshold
  -> Angry
  -> "ふざけるな！"
  -> staff skill penalty
  -> Leave
```

### 「つまみだす」

- 任意の客の個体画面に表示される [A]
- 万引き犯専用コマンドではない [B+]
- 怒る前の短気な客を強制退店させる攻略にも使用されている [B]

本質的にはForceRemoveCustomer(customer)と考えるのが自然。

## 23. 原作バランスとして重要な負の連鎖

原作は各システムが互いに連鎖する。

例:

```
狭いレイアウト
-> 客/店員が詰まる
-> 補充・レジ遅延
-> 客のfrustration上昇
-> 「ふざけるな！」
-> 店員能力-2
-> レジ/補充がさらに遅くなる
-> 売上悪化
```

また:

```
大型化
-> 什器/品揃え増加
-> 潜在売上増加
BUT
-> 清掃/警備/補充負荷増
-> 弱い店員だと店舗評価低下
-> 火災/怒り/渋滞リスク増
```

大型=単純上位互換、AI=常に最適行動、NPCすり抜け等にすると初代らしさを失う。
