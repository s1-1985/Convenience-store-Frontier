# バランステスト

Milestone 9では、同一シナリオと同一シード系列を使い、4つの基準戦略を30日間運営して比較する。

## 実行方法

```bash
npm run balance
```

標準ではシード1〜100を実行し、次のファイルを生成する。

- `artifacts/balance/balance-benchmark.json`
- `artifacts/balance/balance-benchmark.csv`

CI用の短縮実行は次のコマンドを使う。

```bash
npm run balance:ci
```

直接CLIを呼ぶ場合は、シード範囲や出力形式を変更できる。

```bash
npm run build:core
node dist-core/balance/runBenchmark.js --seed-start=101 --seeds=100 --format=both
```

利用可能な引数：

- `--seed-start=1`
- `--seeds=100`
- `--format=summary|json|csv|both`
- `--out=artifacts/balance/custom-name`
- `--strategies=short_low_cost,long_hours`
- `--strict`：Milestone合格条件を満たさない場合、終了コード2を返す

## 基準戦略

### 短時間・低コスト型

- 8〜20時営業
- 人員を絞る
- 売り切り重視
- 一日一回納品
- 行列が深刻な場合だけ昼人員を追加する

### 長時間営業型

- 6〜24時営業
- 欠品防止発注
- 全カテゴリ二回納品
- 夜間負荷が高い場合は夜人員を追加する

### 昼食特化型

- 即食食品の売場を拡張
- 昼人員を最大化
- 即食食品を二回納品
- 欠品が続く場合は全カテゴリ二回納品へ切り替える

### 地域総合型

- 7〜23時営業
- 品ぞろえを均衡させる
- 行列、棚欠品、平常時で作業優先を切り替える
- 地域習慣と安定運営を重視する

## KPI

### 30日利益

30日間の日次利益合計。融資などの資金移動は含めない。

### サービス信頼度

現時点では独立した店舗信頼値がないため、次を抑えた割合を代理指標として使う。

- 行列離脱
- 商品在庫欠品
- バックヤード在庫がある状態での棚欠品

### 生活習慣

30日目の4習慣の地域定着度平均と、自社寄与度平均を分けて記録する。

### 安定性

次を合成した0〜1の指標。

- サービス信頼度
- 資金生存率
- 作業積み残し
- 廃棄効率

### 競争対応

最終7日間の自社・競合間の来店シェアを使う。競合AIの行動回数も別項目で記録する。

## Milestone合格判定

次をすべて満たすと合格になる。

1. 4戦略中3戦略以上が、60％以上のシードで実用判定を得る
2. 一つの戦略が利益・信頼・習慣・安定性・競争対応の全指標で首位にならない
3. 無操作プレイで、朝流出、昼欠品、廃棄、閉店後需要が所定の進行順で60％以上のシードに発生する

合格しない場合もベンチマーク自体は結果を出力する。失敗を隠すのではなく、どの戦略やイベントを調整すべきか確認するために使う。
