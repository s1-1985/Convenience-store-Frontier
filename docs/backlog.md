# 実装バックログ

## 優先度

- P0：動作に必須
- P1：中心体験の検証に必須
- P2：理解・品質を大きく改善
- P3：演出・将来拡張

## Milestone 1：数値シミュレーター

### P0

- 15分単位のゲーム時計
- 30日進行、日次・週次処理
- 決定論的乱数とシード
- 顧客コホート別の時間帯需要
- 営業時間外需要
- 自社・競合・その他の店舗選択
- カテゴリ別購入
- 売上、原価、人件費、現金
- CSVまたはJSONからのパラメータ読込

### 完了条件

- 同じシードと方針で同じ結果になる
- 8〜20時と7〜23時で需要・費用・利益が異なる
- 30日を停止せず実行できる

## Milestone 2：在庫・発注

### P0

- 商品・カテゴリ定義
- 在庫バッチと期限
- 先入れ先出し
- 自動発注
- 一日一回納品
- 欠品と廃棄

### P1

- 即食食品のみ二回納品
- 全カテゴリ二回納品
- 棚在庫とバックヤード在庫
- 欠品原因の分類
- 商品販売帳簿
- 簡易集計レジ

### 完了条件

- 弁当発注を増やすと欠品が減り、廃棄が増える
- 二回納品で調整力が増すが、費用も増える
- 二回納品が低売上時には不利になる

## Milestone 3：店舗オペレーション

### P0

- 時間帯別人員
- レジ作業
- 補充作業
- 清掃作業
- 納品受入
- 発注・記録作業
- 優先順位による能力配分
- 未処理作業の繰越
- 行列と離脱

### P1

- 清潔度
- スタッフ士気
- 店長疲労
- 突発欠勤

### 完了条件

- レジ優先で行列は改善するが、補充または清掃が悪化する
- バックヤードに在庫があっても棚欠品が起きる
- 長時間営業で夜間の作業負荷が増える

## Milestone 4：生活習慣

### P1

- 顧客の14日利用履歴
- 朝食購入習慣
- 外部昼食調達習慣
- 夜間買い物習慣
- 少量即時購入習慣
- 習慣による需要補正
- 地域行動割合
- 自社寄与と市場成長の分離

### 完了条件

- 安定運営により同じ顧客層の利用頻度が上がる
- 市場成長後は競合売上も増え得る
- 自社欠品時に習慣化客が競合へ流れる

## Milestone 5：競合AI

### P1

- 3日ごとの戦略判断
- 営業時間変更
- 弁当強化
- 飲料値下げ
- 雑誌・日用品強化
- 観測可能情報だけを使う認知処理

### 完了条件

- プレイヤーが朝市場を育てると競合が朝営業を強化する
- 昼食市場成長後に競合が弁当を強化する
- 競合が常に即時・正解反応をしない

## Milestone 6：基本UI

### P0

- 店舗メイン画面
- 時間操作
- 営業時間設定
- 発注方針
- 人員設定
- 作業優先順位
- 日次レポート

### P1

- 売場面積設定
- 在庫・廃棄分析
- 欠品原因表示
- 地域レポート
- 競合レポート
- 通知の重要度と自動停止

### 完了条件

- デバッグ表示を使わず主要問題を発見できる
- プレイヤーが個別商品を毎日操作しなくても経営できる

## Milestone 7：店内可視化

### P1

- 代表顧客
- 入店、棚移動、レジ待ち、退店
- 行列
- 空棚
- 閉店後に通過する客
- 常連表示

### P2

- 店員のレジ、補充、清掃、納品表現
- 時計を見る客
- 商品を探す客
- 廃棄演出

### 完了条件

- テスター60％以上が数値を見る前に問題を察知できる
- 表示上の現象と内部数値が矛盾しない

## Milestone 8：30日シナリオ

### P1

- 1〜30日の条件イベント
- チュートリアル
- 代替解決の検知
- 最終評価
- 企業史生成
- 緊急融資と運営崩壊からの再建

### 完了条件

- 初見プレイヤーが30日を完走できる
- 45〜70分のプレイ時間に収まる
- 重要判断が最低6回発生する

## Milestone 9：バランステスト

### P0

- 短時間・低コストAI
- 長時間営業AI
- 昼食特化AI
- 地域総合AI
- 100シード一括実行
- KPI比較出力

### 合格条件

- 4戦略中3戦略以上が実用範囲
- 一戦略が利益・信頼・習慣・安定性をすべて支配しない
- 無操作プレイで朝流出、昼欠品、廃棄、閉店後需要が順に発生する

## 試作中の禁止事項

次は試作合格まで追加しない。

- 2号店
- 全国マップ
- PB開発
- ATM、宅配、公共料金収納
- 店内コーヒー
- M&A
- フランチャイズ
- 自由建築
- 車両単位の配送
- 店員個人ドラマ
- オンライン機能

新案は `docs/future-ideas.md` へ退避し、現行バックログへ混ぜない。
